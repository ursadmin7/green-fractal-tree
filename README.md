# 🌳 Green Fractal Tree

A fractal tree visualization built with Python and Turtle graphics, demonstrating recursive branching patterns with green branches growing upward and downward.

## ✨ Features

- 🌿 Recursive tree branching
- 🌳 Upward and downward branch growth
- 🎨 Green-themed tree visualization
- 🐍 Built with Python Turtle graphics
- 📐 Demonstrates recursion and fractal patterns

## 🛠️ Requirements

- Python 3
- Turtle graphics module (included with standard Python installations)

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/ursadmin7/green-fractal-tree.git
cd green-fractal-tree
```

Run the program:

```bash
python green_fractal_tree.py
```

- Recursion
